# Contact

Email: [contact@patriotinlays.com](mailto:contact@patriotinlays.com)

## Corrections and suggestions

If you find an error, or have an idea for a tool or guide that would help, please tell us at the email address above. Each correction is checked against the cited source before the page is updated. Every suggestion is read, though not every one can be added.

For a correction, please include the page address, the sentence in question, and the official source that shows the correction.

This site cannot review individual lineage applications or tell you whether an ancestor will be approved; only a lineage society's genealogists can do that.

Every guide lists the official sources it relies on, so you can check any statement directly against them.
