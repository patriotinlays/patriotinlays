# Contact

Email: [contact@patriotinlays.com](mailto:contact@patriotinlays.com)

Corrections are the most useful message you can send. Please include the page address, the sentence in question, and the official source that shows the correction, so it can be checked against the Source Manifest before the page is changed.

This site cannot review individual lineage applications or tell you whether an ancestor will be approved; only a lineage society's genealogists can do that.

Every guide lists the official sources it relies on, so you can check any statement directly against them.
